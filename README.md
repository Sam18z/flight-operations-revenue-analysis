# ✈️ Domestic Airline Operations & Revenue Analysis

## 📌 Project Overview

An Excel-based dashboard project focused on analyzing domestic airline operations, revenue, passengers, flight performance, and profitability.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Dashboard Creation

## 📊 Dashboard Analysis

- Airline-wise Revenue
- Airline-wise Passengers
- Region-wise Revenue
- Flight Status Analysis
- Total Flights
- Total Passengers
- Total Revenue
- Total Profit

## 🎯 Key Features

- Interactive dashboard
- KPI cards
- Month, Airline & Region slicers
- Pivot-based analysis
- Interactive charts

## 📁 Files

- `Domestic Airline Analysis.xlsx` — Excel dataset, analysis and dashboard
- `Domestic Airline Dashboard.png` — Dashboard preview
